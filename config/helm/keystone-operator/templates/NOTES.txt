Keystone operator installed.

  Release: {{ .Release.Name }}
  Namespace: {{ .Release.Namespace }}
  Chart: {{ .Chart.Name }}-{{ .Chart.Version }}

Verify the install:

  kubectl -n {{ .Release.Namespace }} rollout status deploy/{{ include "keystone-operator.fullname" . }}
  kubectl get crds | grep keystone.hexxlock.io
  kubectl -n {{ .Release.Namespace }} get pods -l app.kubernetes.io/instance={{ .Release.Name }}

{{- if .Values.webhook.enabled }}

Confirm the admission webhook is serving:

  kubectl get validatingwebhookconfiguration {{ include "keystone-operator.fullname" . }}-validating-webhook
{{- if .Values.webhook.certManager.enabled }}
  kubectl -n {{ .Release.Namespace }} get certificate {{ include "keystone-operator.webhookCertName" . }}
{{- end }}
{{- end }}

Create your first DatabaseProvider:

  cat <<'EOF' | kubectl -n {{ .Release.Namespace }} apply -f -
  apiVersion: keystone.hexxlock.io/v1alpha1
  kind: DatabaseProvider
  metadata:
    name: my-postgres
  spec:
    host: pg.example.com
    port: 5432
    sslMode: require
    maintenanceDatabase: postgres
    adminSecretRef:
      name: my-postgres-admin
      usernameKey: username
      passwordKey: password
  EOF

Then a LogicalDatabase:

  cat <<'EOF' | kubectl apply -f -
  apiVersion: keystone.hexxlock.io/v1alpha1
  kind: LogicalDatabase
  metadata:
    name: app-db
    namespace: default
  spec:
    name: app_db
    providerRef: my-postgres
    ownerRole: app_owner
  EOF
